# FloraMind AI - Iris Flower Classification

## Overview
FloraMind AI is a Machine Learning project developed to classify Iris flower species using morphological features such as sepal length, sepal width, petal length, and petal width.

## Developer
Madhav Kumar

## Features
- Dataset Exploration
- Data Visualization using Seaborn and Matplotlib
- Correlation Heatmap
- Random Forest Classification
- Accuracy Evaluation
- Classification Report
- Confusion Matrix
- Feature Importance Analysis
- Real-Time Prediction
- Model Saving for Deployment
